## 🎨 Design Tokens

### Spacing
- Card Padding: `p-6` (24px)
- Grid Gap: `gap-6` (24px)
- Border Radius: `rounded-2xl` (16px)

### Typography
- Headers: `text-lg font-bold` or `text-2xl font-bold`
- Body: `text-sm font-medium` or `text-base font-semibold`
- Stats: `text-2xl font-bold`

### Effects
- Blur: `backdrop-blur-xl`
- Shadow: `shadow-lg` or `hover:shadow-xl`
- Scale: `hover:scale-105`
- Opacity: `opacity-50` or `bg-opacity-40`

### Animation
- Duration: `duration-300` (smooth)
- Easing: `ease-in-out` (default)
- Transitions: All major properties animated

---

## 📱 Responsive Behavior

### Desktop (lg and above)
- Card Grid: 3 columns
- Header Metrics: 5 columns in a row
- Full UI visible

### Tablet (md)
- Card Grid: 2 columns
- Header Metrics: 3 columns + wrap
- Adjusted padding

### Mobile (sm and below)
- Card Grid: 1 column (full width)
- Header Metrics: 1-2 columns
- Optimized touch targets
- Larger padding for readability

## 🌗 Dark Mode Transformation

```
LIGHT MODE                          DARK MODE
─────────────────────────────────────────────────
bg-blue-50                      →   dark:bg-blue-900/10
bg-white                        →   dark:bg-slate-800
text-slate-900                  →   dark:text-white
border-blue-200                 →   dark:border-blue-800
shadow-lg                       →   shadow-lg (same)
backdrop-blur-xl                →   backdrop-blur-xl (same)
```

All 50+ components automatically switch colors when dark mode is enabled!

## ✨ Animation Examples

### Card Hover Animation
```
Initial State:
- Scale: 100%
- Shadow: sm

On Hover:
- Scale: 105%
- Shadow: xl
- Glow: opacity-20
- Duration: 300ms
```

### Button Click Animation
```
On Click:
- Background: darken by 1 shade
- Duration: 100ms
- Effect: Press down, spring back
```

### Toggle Dark Mode
```
On Toggle:
- All backgrounds: transition
- All text colors: transition
- Duration: 300ms
- No page reload needed
```
